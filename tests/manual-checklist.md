# Manual interaction checklist

- [ ] Opening `index.html` shows only screen 1.
- [ ] Clicking `Sang trang tiếp theo` opens screen 2.
- [ ] Clicking `Yes` once changes the label to `yes`.
- [ ] Clicking `Yes` twice changes the label to `yes lần nữa`.
- [ ] Clicking `Yes` a third time opens screen 3 and shows floating hearts.
- [ ] Clicking `No` changes the label to `no` and moves the button.
- [ ] Repeated `No` clicks cycle through `đừng no mà` and `hong đượttt nooo`.
- [ ] The `No` button never moves off-screen on a phone-sized viewport.
